# 通用单主播歌单

基于 SvelteKit 和 Supabase 的单主播歌单模板。观众查歌、点歌，主播在后台管理歌曲与愿望单。每个站点独立部署、独立保存数据，可配置自己的域名与页面风格。

基于 [QingKong Songlist](https://github.com/vtbs-infra/songlist-qk)，保留原作者声明及 LICENSE。

## 功能

| 功能               | 简介                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------ |
| 公开歌单           | 支持搜索、语言/标签/状态筛选、歌曲名排序、随机选歌和点击复制点歌信息。                     |
| 愿望单             | 观众无需登录即可提交想听的歌曲，管理员在后台审核处理。                                     |
| 歌曲管理           | 后台添加、编辑、删除歌曲，设置原唱、语言、演唱状态及是否公开。                             |
| 歌曲软件导入       | 后台“添加歌曲 → 歌曲软件导入”支持网易云、酷狗和 QQ 音乐的单曲与公开歌单分享链接。          |
| 后台标签与排序     | 支持选择已有标签、批量追加标签，以及默认、歌曲名、导入次序的升降序排序。                   |
| 页面文字与背景设置 | 后台“页面配置”可修改首页与导航文字、网页标题和描述、头像、背景及背景模糊度，支持图片预览。 |
| 图标与鼠标指针     | 支持自定义导航图标、网址图标及静态/动态鼠标指针。                                          |
| 数据备份与恢复     | 后台“数据配置”可导出、恢复歌曲、愿望单、页面配置及引用素材。                               |

音乐导入仅获取歌曲信息，不下载音频；私密歌单或平台限制可能导致解析失败。

页面设置直接展示常用资料，文字与图标、鼠标指针和点歌复制格式默认折叠，统一通过底部固定按钮保存。点歌前缀默认“点歌”，支持自定义和恢复默认；复制内容为“前缀 + 一个空格 + 完整歌名”。

## 快速测试

需要 Node.js 20.19+ 或 22.12+。在项目目录执行：

```powershell
npm ci
npm run dev:local
```

打开 [本地测试站点](http://127.0.0.1:5183)，后台账号为 `admin@local.test`，密码为 `Local-only-0929!`。

测试数据保存在内存中，退出后清空，不连接正式数据库。关闭终端后，重新执行 `npm run dev:local` 即可再次测试。

## 部署与维护

| 项目     | 说明                                                                       |
| -------- | -------------------------------------------------------------------------- |
| 部署方式 | 每位主播创建独立的 Vercel 和 Supabase 项目，代码共用此仓库的 `main` 分支。 |
| 页面入口 | 公开歌单 `/`，后台登录 `/admin/login`，后台管理 `/admin`。                 |
| 数据存储 | 歌曲、配置和账号保存在本站的 Supabase，图片等素材保存在 Supabase Storage。 |
| 代码更新 | 推送 `main` 后，连接该分支的 Vercel 项目自动部署；各站点数据保持独立。     |

- [部署指南](DEPLOYMENT.md)：首次部署、环境变量、已有站点升级。
- [配置示例](.env.example)：数据库连接与可选品牌配置。
- [更新日志](更新日志.md)：历史功能更新记录。

## 常用命令

| 命令                                                                          | 用途                                                       |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `npm run dev:local`                                                           | 启动隔离测试站点。                                         |
| `npm run dev`                                                                 | 使用本地 `.env` 启动开发服务；连接正式库时会修改正式数据。 |
| `npm run check`                                                               | 类型与 Svelte 检查。                                       |
| `npm run build`                                                               | 生产构建。                                                 |
| `npm run preview`                                                             | 预览生产构建。                                             |
| `npm run test:music-import` / `test:tags` / `test:appearance` / `test:backup` | 导入、标签、页面配置和备份测试。                           |
| `npm run test:security` / `test:analytics`                                    | 安全与访问统计测试。                                       |

## 技术栈

页面设置浏览器回归可执行 `npm run test:page-settings`，使用独立的本地测试数据库，需要 Playwright 和 Edge；也可通过 `npm run test:page-settings -- <Playwright 的 index.mjs 路径>` 使用已有安装。

SvelteKit 2 · Svelte 5 · Vite 8 · Tailwind CSS 4 · Supabase · Zod 4 · `@neteasecloudmusicapienhanced/api`
